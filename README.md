# دفتري - موقع التطبيق

1. أنشئ مستودع عام على GitHub باسم daftari وارفع محتويات هذا المجلد.
2. Settings > Pages > Deploy from a branch > main / root.
3. عدّل data.json: غيّر YOUR_USERNAME لاسم حسابك.
4. للوحة التحكم: افتح /admin.html، أنشئ Fine-grained token لهذا المستودع بصلاحية Contents (Read and write) وصلاحية Issues (Read)، والصقه هناك.
5. الآراء بتوصل كـ Issues بعنوان يبدأ بكلمة رأي، وبتظهر في لوحة التحكم.
